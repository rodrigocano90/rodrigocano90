# Rodrigo Cano — Design Portfolio

Versión exportada para desplegar en Vercel con Next.js.

## Subir a Vercel

1. Descomprimí este archivo.
2. Subí la carpeta a un repositorio de GitHub, GitLab o Bitbucket.
3. En Vercel, elegí **Add New → Project** e importá el repositorio.
4. Vercel detectará automáticamente Next.js. No hace falta cambiar los comandos ni agregar variables de entorno.
5. Presioná **Deploy**.

También podés desplegarla desde la terminal con `npx vercel`.

## Desarrollo local

```bash
npm install
npm run dev
```

Abrí `http://localhost:3000`.

## Producción

```bash
npm run build
npm start
```
